# 播音主持艺考班主任工作台

面向播音主持艺考班主任的**纯前端**教学管理工作台，已针对 iPhone 等手机屏幕重新设计 UI，同时兼容电脑浏览器。

## 在线使用

👉 **https://laoyuhao.github.io/broadcast-workbench/**

手机浏览器（Safari / Chrome / 微信）直接打开即可。建议「添加到主屏幕」，用起来跟原生 App 一样。

## 功能

| 模块 | 说明 |
|---|---|
| 数据总览 | 学生数、模考次数、平均分等统计卡片 + 成绩趋势图表 |
| 学生档案 | 学生增删改查、搜索、按班级/状态筛选 |
| 模考成绩 | 多维度成绩录入、成绩单管理、Excel 导入 |
| 成绩分析 | 单人多维雷达图、趋势分析、自动生成分析报告 |
| 课程表 | 月历视图、课程安排 |
| 数据管理 | 本地备份导出、导入恢复 |
| 云端同步 | 通过 GitHub 实现多设备、多位老师共用一份数据 |

## 手机端 UI

- 左侧滑出**抽屉导航**（汉堡按钮打开，点遮罩关闭）
- 固定**顶部栏**实时显示当前所在页面
- 模态框改为**底部弹出 Sheet**，符合 iOS 交互习惯
- 按钮放大到适合拇指点触，输入框 16px 字号避免 iOS 自动缩放
- 适配 iPhone 刘海 / 灵动岛安全区
- 屏幕宽度 ≥ 769px 自动切回电脑版侧边栏布局，一个文件通吃两端

## 云端同步

数据默认只存在浏览器本地（localStorage），断网也能正常使用。开启同步后会读写本仓库的 `data.json`。

配置方法：打开工作台 →「数据管理」→「云端同步」→ 填入 GitHub Token 和用户名 `Laoyuhao` → 保存。

其他老师填入同一组信息即可共用数据。同步规则：以 `updatedAt` 时间戳双向合并，删除通过墓碑标记传播，多人同时编辑不冲突（最后修改者优先），每 60 秒自动拉取一次。

## ⚠️ 隐私提醒

本仓库为 **Public（公开）**，因此 `data.json` 中的学生姓名、成绩等信息**任何人都能访问下载**。

如需保护数据，可另建一个名为 `broadcast-workbench` 的 **Private** 仓库专门存数据，页面另放公开仓开 Pages —— 程序里同步仓库名是写死的，因此无需修改任何代码。

## 技术说明

单文件纯前端应用，无框架、无构建步骤。图表使用 Chart.js，存储使用 localStorage + GitHub Contents API。
